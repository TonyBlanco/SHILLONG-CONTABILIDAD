## Technical Details

### Problem Solved
Export of "Modelo evolutivo presupuestario" was using embedded sample data in templates instead of real calculations from `data/shillong_2026.json`.

### Solution Approach
- Programmatic generation over template filling ensures fresh data every export
- Reuses existing calculation functions from `ui/InformesView.py`
- Maintains layout and formatting of original template
